# مصاريفي · Msarifi

تطبيق ديال تسيير الفلوس بالدارجة (PWA). كلشي كيتخبى فالتيليفون ديالك (localStorage)، بلا سيرفر وبلا حساب.

- Dépenses / Revenus بسرعة (`?add=1` كيحل الشاشة ديال الزيادة نيشان، مزيان لـ Back Tap فالآيفون)
- Budget ديال كل فئة مع التنبيهات
- Crédits، Créances، Actifs، Location (Airbnb / كرا عادي)
- Export / Import JSON
